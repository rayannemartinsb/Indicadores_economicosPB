# Sistema de Acompanhamento de Indicadores Econômicos da Paraíba

## Sobre o projeto

Este projeto tem como objetivo organizar e acompanhar indicadores econômicos do estado da Paraíba, com a finalidade de subsidiar a elaboração de um boletim econômico para o Corecon-PB.

## Indicadores

- PIB estadual e municipal
- Volume de vendas do comércio
- Volume de serviços
- Emprego formal
- Taxa de desocupação
- Exportações e importações
- Operações de crédito
- Arrecadação de ICMS

## Estrutura do repositório

- data/raw/: dados originais coletados.
- data/processed/: dados tratados.
- docs/: documentação das fontes e variáveis.
- notebooks/: códigos de aquisição e análise.
- outputs/: resultados gerados.
